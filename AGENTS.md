# FuneralControl - Diretrizes do Projeto

## Sobre o Projeto

Sistema web para gestão e controle de planos funerários, abrangendo cadastros de titulares e beneficiários, gestão de contratos digitalizados, faturamento mensal e controle de inadimplência.

## Stack Técnica

- **Frontend**: React 19, Tailwind CSS v4, shadcn/ui, Lucide Icons, TanStack Router / TanStack Start.
- **Backend**: TanStack Start Server Functions, Node.js.
- **Banco de Dados**: PostgreSQL nativo (`pg`).

## Diretrizes de Desenvolvimento

- Manter código limpo e componentizado.
- Todas as mensagens para o usuário e regras de negócio em Português do Brasil (pt-BR).
